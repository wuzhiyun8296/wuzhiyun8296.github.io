# 命名与查词表

## 一、溪凌王国（守旧 · 矿业国度）

- **风格**：名称古朴，与矿物、山岩、古堡相关，体现守旧传统。

| 层级 | 西式名称 | 说明 |
|---|---|---|
| 王域（首都直辖） | Crownshire | 江黔城所在，王室直辖核心区 |
| 北域（矿区） | Northminster | 北方温暖地区，主要铁矿区 |
| 南域（宝石区） | Southminster | 南方寒冷地区，宝石与稀有矿产 |
| 西关域（边境关隘） | Westgate | 靠近影灵王国的边境通道 |
| 东岭域（山地） | Eastridge | 东部山区，富产魔导石矿脉 |

### 完整示例

溪凌王国 · 北域（Northminster）· 铁砧区（Anvil District）· 深矿镇（Deepmine Town）

## 二、幻翎王国（宗教为先 · 粮食国度）

- **风格**：名称与宗教、丰收、大地相关，体现“圣”与“粮”双重主题。

| 层级 | 西式名称 | 说明 |
|---|---|---|
| 圣域（首都直辖） | Sanctumshire | 赤北城所在，大主教驻跸之地 |
| 金穗域（产粮区） | Goldwheat | 中部平原，王国的粮仓 |
| 圣烛域（教会领地） | Saintcandle | 教会直属领地，修道院密集 |
| 牧野域（畜牧区） | Shepherdsfield | 南部丘陵，畜牧与羊毛 |
| 圣泉域（宗教圣地） | Holywell | 有“圣泉”传说，朝圣中心 |

### 完整示例

幻翎王国 · 金穗域（Goldwheat）· 麦仓区（Granary District）· 丰饶镇（Harvest Town）

## 三、影灵王国（明君统治 · 兵器国度）

- **风格**：名称与兵器、钢铁、城堡相关，体现“武备”与“皇权斗争”的双重底色。

| 层级 | 西式名称 | 说明 |
|---|---|---|
| 王冕域（首都直辖） | Crownhold | 晨昏城所在，王权核心 |
| 铸剑域（兵器主产区） | Swordford | 最大兵工厂所在地 |
| 铁砧域（锻造区） | Anvilshire | 高级盔甲与精密兵器锻造 |
| 哨卫域（边境防线） | Watchmarch | 靠近帝国边境，驻军重地 |
| 暗影域（谍影之地） | Shadowmere | 王子势力盘踞，权力斗争暗处 |

### 完整示例

影灵王国 · 铸剑域（Swordford）· 剑刃区（Blade District）· 淬火镇（Forge Town）

## 四、卫律联合城邦国（松散联邦 · 航贸国度）

- **风格**：名称与海洋、城邦、议会相关，体现“松散联邦”与“海洋贸易”特色。因为是比较松散的联邦制，所以区域的划分比较灵活。

| 层级 | 西式名称 | 说明 |
|---|---|---|
| 首都邦（名义统领） | Prime City | 极夜城所在，名义上的首都城邦 |
| 贸易邦（海商联盟） | Merchant League | 最大港口城邦群，商会势力强 |
| 议会邦（政治中心） | Councilport | 各城邦代表集会的城邦 |
| 自由邦（独立城邦） | Freetown | 最松散的城邦，几乎自治 |
| 护卫邦（军事同盟） | Shieldhold | 负责联合防御的城邦 |

### 完整示例

卫律联合城邦国 · 贸易邦（Merchant League）· 海港区（Harbor District）· 帆船镇（Sail Town）

## 五、魔族首都·凌城

魔族体系与帝国不同，凌城不设域/区/城三级划分。

### 建议

凌城作为魔族首都，由革命者团队（魔王团队）直接管辖。

周边地区可按部落或军事片区划分，如：

- **核心堡（Core Keep）**：凌城中心，魔王团队驻地

流放地（Exile Ground）：外围区域，新来者聚居

军戍区（Garrison March）：防御军队驻扎区

铁匠谷（Forge Valley）：矮人与魔族合作打造的兵器区

### 完整示例

凌城 · 核心堡（Core Keep）· 革命者大厅
