# 城镇与地理

## 城镇与农村

### 城镇描述

这是一个巨大的城镇，有着六边形的城墙保卫着，穿过城洞，卫兵会查验你的身份，并且进入之后有着商业街，里面有服装店，护具店，饰品店，面包店.....再往前走，城市中心有一个巨大的广场，上面矗立着圣骑士的雕像，旁边是一座宏伟的教堂，城市的教堂的旁边便是警察局，同时在这条街上还有这旅馆，饭店，每一个人都十分的友好，冒险者公会位于教堂的旁边，周边有着武器店，饭店，等各种各样的店铺。城市拥有着完好的下水道系统。但是在祥和的城市之中也有着黑暗的一面，这里的领主征收高额的税收，人们生活在这里苦不堪言，但是人们依旧保持着良好的心态，相信总有一天领主会被推翻。同时，城市里也有着反抗组织，他们会时不时的发动袭击，以谋求推翻领主，但是由于领主的暴力镇压，他们几乎销声匿迹了。

### 农村描述

在乡下，路边的景色十分的美丽，但是，在这美丽的背后，却拥有着十分黑暗的现实，佃农们被贵族压迫，一年收获的大部分粮食被贵族收走，小部分粮食才可以养家糊口，即便是再辛苦的劳作，一年到头也吃不到几次饱饭，人们的怨气十分的多，当然脱离领主是可以的，但是要缴纳巨额的赎金，没有几个人交的起，同时自己的子孙如果是在这个土地上出生，那么自己的子孙也将会是领主的佃农。

领主拥有着豪华的别墅，拥有着十几个奴隶与仆人，他们常常把奴隶作为发泄的对象，同时也对自己的仆人拳打脚踢。同时部分实力强劲的领主甚至会抢夺他人的财宝，毁坏村子，抢夺自己看中的人，也会滥用酷刑。当然里面有好的领主，但是毕竟是少数。

- 农村也有自由的村落，里面的人们幸福的生活在一起，同时他们也过着与世无争的生活。
