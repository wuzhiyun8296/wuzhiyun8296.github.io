# 势力与种族

- **势力**：人族：与魔族敌对，帝国统领人族大军
- **人类军队**：抵抗魔族入侵
- **圣骑士**：攻打魔族的军队（法师+骑士）
- **冒险者**：接受委托的人
- **魔族**：与人族敌对，魔王统领魔族大军，但是魔族并不是单独的一个势力，而是由不同的团体的总称。
- **魔物**：是刷经验的好东西，其内部有核心
- **魔族军队**：攻击人类城镇
- **冒险者公会**：提供身份认证与委托的

幻想域（The Veiled Kindred Spirits——TVKS）：由穿越者所组成的联盟，为穿越者提供住所，工作和庇护，与冒险者公会有着极大的联系

- **凌霄**：由穿越者组成的第二个组织，与幻想域为独立关系，或者说这两个几乎不知道对方的存在。
- **镜月**：没想好
- **医师公会**：是由医生，贵族，教会所组成的垄断性的组织。
- **十二圆桌骑士**：统治帝国的实际掌权者，他们是残暴的统治者，在他们的统治下，人们苦不堪言。
- **商会**：与贸易经济相关的组织。
- **教会**：宗教性的组织。
- **异端裁决所（凌玑阁）**：穿越者与帝国联合（隶属十二骑士），清除穿越者的组织。
- **人族的详细描述**：人族的组成十分复杂，在人族的领地有多个王国：

帝国（腐败严重，权力被骑士所控制）：是势力最强大的国家，由帝国所率领的人族军队，与魔族对抗，帝国拥有强大的兵力，与相对完整的工业体系，还有强大的商会，其是由国王进行统治，但是，国王并没有实权，真正实行统治的是十二圆桌骑士。

溪凌王国（守旧）：与帝国合作的国家，生产各种矿石，宝石，拥有自己的军队，但是工业体系薄弱，但是他们没有想改变现有的生产方式，对一切的新事物，新技术保持着疏离的状态。

幻翎王国（宗教为先）：盛产粮食作物，是人族最重要的粮食供应国，但是由于该国的压迫十分严重，导致国内一直动荡不安，时常有人被指认为异教徒，并且教士在该国内的地位极高，拥有着许多特权。

影灵王国（明君统治）：盛产兵器，盾牌等兵器，是人族重要的武器供应国，拥有自己的军队，但是老国王病重，内部皇权斗争激烈，甚至勾结其他势力试图争夺皇位，但是国家在老国王的领导下欣欣向荣，他们无时无刻想脱离帝国的控制。

卫律联合城邦国（由松散的联邦所组成的国家，参考希腊）：可以自给自足的王国，拥有自己的军队，但是十分反感帝国，但是整个国家十分松散，各城邦有自己的法律，但是各国在名义上被该国首都城邦统治。

### 魔族的详细描述

魔族：被流放的人，而且大部分是革命者，但也有真正的穷凶极恶的罪犯。那么为什么取名为魔族呢，是因为帝国的不断渲染和宣传，编造虚假信息，让民众们误以为他们穷凶极恶，所以得名魔族，而且，有一只军队常常带着面具打仗，而且战斗力极为强盛，他们被那些败逃回来的士兵添油加醋的描述了一番，更加深了人们对魔族的刻板影响，以至于许多人认为魔族人类的面貌是伪装的，当然魔族是由多个组织的总称，每个组织的组成都是不同的。

魔王：统领魔族一切的王，但是魔王真是的是魔王吗？当然不是，魔王只不过是一个代号罢了，其实，根本没有魔王。要说硬说魔王，其实是一个团队，这是由革命者所组成的团队，而这个团队在被流放的人里面是最强的。这个团队有一个代表，在台上宣布团队所做的决定，所以被人称为魔王。

### 种族

- **人族**：就是人
- **魔族**：被流放的人
- **精灵族**：拥有极高的魔法造诣
- **矮人族**：精通兵器制作
- **亚人族**：通常指兽人。
- **地位**：对人族而言：人族>矮人>低魔力者>亚人

描述：在这个人人都有魔力的世界，魔力的高低就成为了一个人的身份地位的象征，贵族之间，魔力值越高，身份往往越尊贵，但这不是绝对的，贵族地位往往还与你所做的贡献有着极大的关联。在平民之间，魔力也是评价一个人地位的高低，魔力高的人看不起魔力低的人，因此，人们在生活中，往往不会暴露自己的魔力值，但是，你的魔力值一旦暴露，且被众人所知，将会被所有人看不起。

- **货币**：贝勒（Bale），价值参考中世纪。
