# 世界总览

这是一个与现实世界不同的世界，这里拥有着2种力量，一种是物理的力量，一种是魔法的力量。但是，由于魔法的存在，这个世界的发展进程也十分的缓慢，即使这个世界拥有很长的历史，但是现在依旧是君主专治的社会，农民与贵族的矛盾日益渐深。

### 力量

物理力量、魔法力量

- **物理力量**：使用物体进行行动所产生的效果

### 魔法力量

魔力：魔力是使用魔法的前提，只有拥有了魔力，才可以使用魔法，魔力的性质决定了可以使用什么种类的魔法，这是绝对的，魔力的强度决定的使用魔法的强度，但是这是相对的，可以通过后天的魔法练习来提高魔力的强度（注意，无法使用魔法的人，无法提升魔力），在这个世界中魔力分为初级，中级，高级等级，而穿越者无法测量出等级，因此被认为为初级一阶。魔力可以类比为电力，拥有与电相似的性质。

- **攻击系魔法**：可以造成伤害，或者范围伤害的魔法
- **防御系魔法**：可以减弱伤害或者预防即将到来的伤害
- **治愈系魔法**：可以减少或者恢复伤口，疾病，治愈重大伤害或者精神伤害
- **精神系魔法**：可以通过精神攻击来使敌人受伤或者死亡
- **神秘系魔法**：不同于以上魔法系的魔法

使用魔法：需要吟唱相应的魔法咒语，魔法阵会出现在魔力集中的位置，当咒语吟唱完毕时，魔法将放出。但是如果魔力强大的话，也可以直接使用无吟唱魔法。

- **说明**：魔法怎么能简单的分类呢，只不过可以让我们对魔法有一个简单的认识罢了。

### 魔法的分类

- **初级魔法**：一阶，二阶，三阶
- **中级魔法**：一阶，二阶，三阶
- **高级魔法**：一阶，二阶，三阶
- **超越魔法**：一阶，二阶，三阶

说明：魔法阶数越大，魔力越强。其中初级魔法与中级魔法的一二阶，是根据魔法的威力来划定的，其中特别的是中级魔法三阶段需要会使用融合魔法（同时使用两种及以上的魔法）或者使用单魔法，但是威力需达到高级魔法一阶的程度。同时随着等级的升高，提升等级的难度也成指数级增长。在高级魔法的人数很少，在超越魔法阶段的人更加少。通常来讲，为了世界的和平与安全，一般发现有高级三阶魔法潜力的人会直接进行毁灭。

- **初级魔法一阶**：会用就行
- **初级魔法二阶**：可以对生物造成客观的伤害
- **初级魔法三阶**：可以直接杀死普通的魔物
- **中级魔法一阶**：可以对C级生物造成客观的伤害
- **中级魔法二阶**：可对B级生物造成巨大伤害
- **中级魔法三阶**：可以对A级生物造成巨大伤害，且会两种及以上的融合魔法，或单魔法达到高级一阶魔法。
- **高级魔法一阶**：可以对S级魔物造成客观的伤害。
- **高级魔法二阶**：可以直接杀死S级魔物
- **高级魔法三阶**：使用三个及以上的融合魔法并可以将魔法叠加使用，或两个融合魔法威力达到超越魔法一阶。
- **超越魔法一阶**：有实力独自对抗成体系的军队，可以直接毁灭城市。
- **超越魔法二阶**：可以直接毁灭大量城市，或一个国家
- **超越魔法三阶**：可以直接毁灭星球
