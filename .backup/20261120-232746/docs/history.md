# 历史模拟

拖动时间轴，查看各势力版图随纪元更迭的扩张与覆灭。

事件是唯一真相：每一条历史事件只记录「哪个据点易主」，版图由据点在当前纪元下的归属自动划分出来。

<HistoryMap />

::: tip 数据从哪来
本页只做展示。纪元、势力、据点和事件都在后台的「历史模拟」插件里编辑，保存后刷新本页即可看到最新推演结果。
:::
