📖 科技树 · 使用说明

这是一个「什么阶段该点什么科技」的检查表，不是游戏里的科技树。
写世界设定时用它避免「石器时代搞中央集权」「没造纸先有印刷」这类漏洞。
① 先选主题
顶部一行是主题：文明 / 魔法 / 古代中国 / 穿越者通用。 点一个，下面的科技列就换成这条线。
② 再选「标准」还是「穿越者」
🏠 标准发展：本地人靠自己摸索，一步都不能跳。
🧭 穿越者发展：外来者带着现代常识，可以跳过几百年试错——但会被盯上。
③ 看每个时代该做什么
每个时代的标题下有 🏛️ 适配政体，说明这个阶段什么样的治理撑得住。
两个小按钮：📋 路线 按依赖顺序排出「先点什么后点什么」；🏛️ 政体 展开讲讲为什么合适、代价是什么、什么时候该变。
④ 点科技看详情
点任意科技，右侧会显示：它是什么 / 为什么这个阶段做 / 对世界的影响 / 前置条件 / 什么时候该点。
同时树上会亮起来：黄色是它的前置链，蓝色是它能解锁的东西。
⑤ 标记「已掌握」
详情里点 ✓ 标记已掌握，卡片会变绿、右上角进度条往前走。
进度存在 library/科技树/进度.json，换设备也能同步。
⑥ 加你自己的时代
点「➕ 自定义」，可以新建时代、往任意时代里加科技，存在 library/科技树/数据.json。
💡 穿越者线顶部那句「结合当时环境，小心被发现哦」不是装饰：建议每点一项，都想清楚 谁会受益、谁会受损、你怎么解释它的来源。
