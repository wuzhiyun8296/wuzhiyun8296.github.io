⚠️ 读取配置失败

{{ cfgError }}
后端没有这个接口，说明现在跑的 Node 进程还是旧代码。

按顺序试，一般第 1 步就好：
1. 彻底重启（不是点按钮重启）
　· 关掉所有黑色命令行窗口
　· 打开任务管理器 → 找到所有 node.exe → 结束任务
　· 重新双击「一键启动.vbs」或桌面快捷方式
2. 还不行 → 修文件
　· 后台顶栏「🧰 工具 → 🔧 修复文件」，重新下载一遍
　· 修完再彻底重启一次
3. 判断到底是哪种情况
　· 浏览器直接打开 http://localhost:3001/api/firewall/config
　· 显示 404 → 跑的是旧进程（回到第 1 步）
　· 显示一大段 JSON → 后端是新的，只是本页缓存了，Ctrl+F5 强刷
常见原因：
1. 后台没启动或刚重启还没起来 → 点上面的「重试」
2. 浏览器打开的是旧地址（比如换了端口）→ 重新打开后台页面
3. 浏览器缓存了旧页面 → Ctrl+F5 强刷

访问限制

仅允许本机访问 开启后只监听 127.0.0.1，同一 Wi-Fi 下的其他设备、手机都连不上这台电脑的服务。
代价：手机/平板访问前台会失效。
限制跨域来源 只允许来自本机页面的请求，防止你随手打开的陌生网页偷偷读取本地数据（推荐保持开启）。
记录访问日志 在内存里保留最近 200 次接口调用（IP / 时间 / 路径），重启后清空。
⚠️ 设置已保存，但需要重启后台才会生效。
